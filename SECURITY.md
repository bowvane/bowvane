# Security Policy

A browser handles your logins, so security reports matter a lot.

**Please do not open a public issue for a vulnerability.** Use GitHub's private vulnerability reporting (Security tab → "Report a vulnerability") instead, or email **security@<domain>**.

Include the version, steps to reproduce and the impact you observed. We aim to acknowledge reports within 72 hours.

Supported versions: only the latest release receives security fixes during the alpha.
